**Sync is not a backup** · it copies deletions too.

| You mean | Answer |
|---|---|
| *My data on a new phone* | sign in · without account: a backup file |
| *Give me my data* | `.moneykoi` file · *Download all data* · both Pro |
| *Undo what I broke* | partly · a file rewinds to the last backup |

## The tools

| Tool | Who | Plan | Where |
|---|---|---|---|
| **Create a backup** | owner · admin | Pro | Backup & restore |
| **Restore** | everyone | free | Backup & restore · *Welcome back* › *Restore* · tap the file |
| **Undo changes in this book** | owner · admin | free | restore preview |
| **Backup reminder** | owner · admin | Pro | Notifications |
| **Download all data** | everyone | Pro | *Personal data* |
| **Import bookings** (CSV) | owner · admin | free | Backup & restore · Book menu |
| **Export bookings** (CSV) | everyone | Pro | Backup & restore |
| **Export data** (ZIP) | owner · admin | Pro | Book menu |
| **Erase data** | owner | free | Book menu |

- **import free · export Pro** · decided 2026-10-21 (D-DATA-12)

## The file

- `MoneyKoi-<Book>-YYYY-MM-DD.moneykoi` · a zip
- JSONL per record type · manifest + checksums · `bookings.csv` · README
- optional: photos · `settings.json` · AES-256 passphrase
- one book per file · format v1 · older restore, newer refused
- spec: `moneykoi-supabase/BACKUP_FORMAT.md`
