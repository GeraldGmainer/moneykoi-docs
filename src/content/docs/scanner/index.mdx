The on-device receipt scanner: total, items, review, photos.

| | |
|---|---|
| **Where** | on the phone with ML Kit; nothing goes to a cloud OCR |
| **Flow** | total → items → review; skip items for one booking |
| **Parsers** | per shop, plus a generic one |
| **Save** | one booking per line, every line categorised; merge and undo |
| **Accuracy** | measured on a corpus of real receipts (`scanner-corpus-round` skill) |
