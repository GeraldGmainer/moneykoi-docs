Categories, fixed vs. variable, money signs, and accounts.

| | |
|---|---|
| **Categories** | two levels, only leaves are booked; income and expense |
| **Fixed / variable** | a property of the category, set from the starter set |
| **Signs** | by what a figure is — movement, labelled total, net, level |
| **Accounts** | assets and liabilities; balances maintained by triggers, never summed on screen |
| **Who** | owner and admin change the structure; members read it |
