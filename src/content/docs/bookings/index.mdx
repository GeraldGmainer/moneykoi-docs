The booking form, quick booking, tags, the trash and search.

| | |
|---|---|
| **Shapes** | expense, income, transfer; Balance check adds corrections (no category, no destination) |
| **Entry** | the form (app keypad, Save at the bottom) or one line of quick booking |
| **Tags** | per book; trip mode tags new bookings |
| **Trash** | bookings only, per device, local; a restore is a new booking |
| **Search** | accounts, categories, goals, loans and bookings in one field |
