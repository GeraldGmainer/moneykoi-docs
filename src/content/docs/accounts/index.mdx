## The phone's states

- the phone is a **cache of books**
- who is signed in → what is visible
- logout deletes **nothing**

| State | Account | Own book | Shared Cloud books | Own book features |
|---|---|---|---|---|
| **Local Free** | – | phone | – | Free |
| **Local Pro** | – | phone | – | Pro (store) |
| **Free account** | ✓ | phone, local | sync, all features | Free / Pro |
| **Paused** | ✓ | phone · server keeps a copy | sync, all features | Free / Pro |
| **Cloud** | ✓ | syncs · ≤ 3 owned | sync, all features | Cloud |
| **Signed out** | kept | hidden | hidden | — |

- Free + Pro: **one** own book open · others *Locked until Cloud*
- until **Jan 17** every new account = early adopter with Cloud → free accounts start Jan 17

## Ways into an account

| Door | Where | The phone's book |
|---|---|---|
| **Back up & sync** (claim) | Settings · Profile · drawer *Get Free Cloud* | Cloud → uploaded · else kept on the phone |
| **Join \{book\}** | invite on a phone with a local book | uploaded only with Cloud |
| **Sign in** | Profile | set aside · closed after logout |

## Words

| Word | Means |
|---|---|
| **account** | Google or email sign-in |
| **book** | a household's data |
| **local book** | the one book without an account |
| **Cloud book** | owner has Cloud → all features inside |
| **free account** | no own plan · own book on the phone |
| **paused** | ex-subscriber · sync stopped, phone works |
| **claim** | moving a local book into an account |
| **signed-out books** | kept after logout, hidden |
