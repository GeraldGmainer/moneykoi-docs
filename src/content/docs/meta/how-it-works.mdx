## Run it

```sh
cd moneykoi-docs
nvm use            # Node 24
npm install        # once
npm run dev        # http://localhost:4321
npm run check      # build + health check
```

Search works only in `npm run build && npm run preview`.

## Three sources

| Source | Holds | Rule |
|---|---|---|
| **Code** · `moneykoi-app` | tiers (`feature.dart`) · paywall text (`en.json`) · tests | read on every build · **never** copied |
| **Data** · `src/data/` | catalog · rules · journeys · edge cases · checks · tasks · decisions · releases · diagrams | YAML + schema · wrong field → build fails |
| **Pages** · `src/content/docs/` | overviews · pricing · legal | MDX · tables + lists |

## What is checked

- catalog ↔ `feature.dart`, both ways
- every test link → file exists + contains the name
- every id unique · every cross-link resolves
- every diagram: entry ↔ file · sources exist

## Ids

| Prefix | Kind | Example |
|---|---|---|
| `R-<AREA>-nn` | rule | `R-MON-14` |
| `J-<AREA>-nn` | journey | `J-MON-50` |
| `E-<AREA>-nn` | edge case | `E-MON-08` |
| `C-<AREA>-nnn` | manual check | `C-MON-030` |
| `T-<AREA>-nn` | task | `T-MON-04` |
| `D…` · `Q-…` | decision · question | `D4` · `Q-BOOK-1` |

- ids are **permanent** · Trello, commits, chats cite them
- never renumber · retire by deleting

## Plans

- `src/data/plans/<id>.yaml` → `/plans/<id>/` · one page per context
- two blocks: **Gerald** · **Agents**
- tick → saved to the YAML · only under `npm run dev`
- `ref: T-…` item → state = the task's `status` in `tasks.yaml`
- `text:` item → state = `done: <date>` in the plan file
- agents add items + tick their own

## Releases

- `src/data/releases/<version>.yaml` · items in order
- each item: area + **check ids** · ticks shared with area pages
- notes: *still open* · *fixed since* · *changed since* · *decided*

## Linking

`related:` → *See also* · journey `checks:` · task `waitsFor:` · all cross-area

## Add an area

1. a line in `src/areas.mjs`
2. `src/data/<area>/` · any of the six YAML kinds
3. `src/content/docs/<area>/` · `index.mdx` (facts table + `<AreaFeatures>`) + one page per kind
4. `npm run check`

## Width + text size

| Picker | Options | Default |
|---|---|---|
| Width | 45 · 65 · 85rem · Full | 65rem · phones hide it |
| Text | 16 · 17 · 18 · 20 · 22 · 24px · text only | 18px |

- remembered per browser · add an option in `ThemeSelect.astro`, nothing else

## Diagrams

- *How it works* pages + bottom of area overviews · offline: *Offline-first › How it works*
- one `src/diagrams/<id>.mmd` + one entry in `src/data/diagrams.yaml`
- **Full screen** or click → whole window · tap = 2× zoom · tap again = reset · Esc / **Close**
