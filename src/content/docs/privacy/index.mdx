## What leaves the phone

| What | When | To | Control |
|---|---|---|---|
| Book data | Cloud book only | Supabase (EU) | Cloud |
| Receipt photos | Cloud book only | book storage | — |
| Live prices | no account · Pro · investments | Supabase · whole list · anonymous | *Live prices* |
| Crash reports | on by default | Sentry EU · scrubbed | opt-out |
| Usage stats | after a **yes** | Supabase · 400 days | *Usage statistics* |
| Purchases | buy · restore | store + RevenueCat | — |
| Invite emails | inviting | mail function | — |
| Changelog | opened online | Supabase · anonymous | — |
| Receipt text | **never** | read on the phone | — |

## The four features

| Feature | What | Where |
|---|---|---|
| **App lock** | PIN + biometrics · from the first frame | Settings → App lock |
| **Hide amounts** | *Off* · *Tap to reveal* · *Always* · blur · per device | App preferences |
| **Usage stats** | opt-in · first-party · erased on withdrawal | Privacy & Legal · web Settings |
| **Use on computer** | phone approves a browser by QR | drawer · Cloud |
