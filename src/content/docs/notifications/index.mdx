Local reminders per channel and the in-app inbox.

| | |
|---|---|
| **Where** | scheduled on the phone; no push server |
| **Opt-in** | each channel off until switched on; the OS asks then |
| **Channels** | bills, over budget, entry nudge, goals and loans, balance check, forecast, backup, shared-book status |
| **Inbox** | the bell lists what has been shown, per phone and account |
| **Web** | sends none |
