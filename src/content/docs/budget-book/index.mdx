The Budget Book tab: filter and period scopes, Summary, Transactions, Calendar, category activity.

| | |
|---|---|
| **Scopes** | which bookings (the filter) and which slice of time (the period); a count always names its scope |
| **Month** | starts on any day 1–28 (Settings → Start of month) |
| **Views** | Summary (categorised money only), Transactions (grouped by day), Calendar (net per day) |
| **Export** | what you see |
