- **book** = a household's data · database: `tenant`
- several books per person · **one** active

| | |
|---|---|
| **Kinds** | private (`personal`) · shared (`family`) |
| **Limit** | ≤ 3 owned · memberships unlimited · 2+ own = Cloud |
| **Currency** | one per book · owner changes it |
| **Roles** | owner (fixed) → admin → member |
| **Who pays** | owner · members get every feature inside |
| **Offline** | reading ✓ · managing needs internet |
| **Sync** | only the active book pulled · switch never wipes |

## Roles

| | Owner | Admin | Member |
|---|---|---|---|
| Bookings · receipts · shopping | ✓ | ✓ | ✓ |
| Accounts · categories · goals · loans · investments · rules | ✓ | ✓ | read |
| Invite · remove members | ✓ | ✓ | – |
| Roles · remove an admin | ✓ | – | – |
| Currency | ✓ | – | – |
| Whole-book export · import · backup | ✓ | ✓ | – |
| Booking CSV (Pro) · own data | ✓ | ✓ | ✓ |
| Erase · rename · stop sharing · delete | ✓ | – | – |
| Leave | – | ✓ | ✓ |

## App vs web

| | App | Web |
|---|---|---|
| Manage | any book · swipe to preview | active book only |
| Avatars · rename | ✓ | – |
| Live updates | realtime | next refetch |
| Opens | all books | Cloud books only |
