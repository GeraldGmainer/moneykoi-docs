## What it sells

1. **Sync & share** · Cloud: devices · cloud backup · shared books · web · ≤ 3 books
2. **Deeper insights** · Pro: Analytics · forecast · custom ranges
3. **Money tools** · Pro: investments · shopping lists
4. **Make it yours** · Pro: Home editor · bottom bar · colors · exports · backups

**Free promise**
- subtitle: *Budgeting stays free. Always.*
- Free card: *The full budgeting app on this phone. Forever, at no cost.*
- promises budgeting · **never** "every feature"

## Where free users meet it

| Place | What |
|---|---|
| **Paywall** | Free · Pro · Cloud cards |
| **Plan row** | Settings → *Account* · Free · Pro · Cloud · *Cloud through \{book\}* · *Early adopter* · *Cloud ended* |
| **Locks** | drawer Pro group · quick actions · *Edit home* · every export · saved locked tab |
| **Home nudge** | once · dismissed = gone |
| **Drawer entry** | Free: Pro group, last · *Get Pro* · Pro: *Get Cloud* row · none in Cloud · *Get Cloud free* wins |

## How it behaves

| Case | Behavior |
|---|---|
| **Cards** | owned first, then by price · Free neutral · Pro orange · Cloud blue · picked = ring, not fill |
| **Cloud card** | *Everything in Pro* · monthly/yearly/lifetime · *Everyone in a Cloud book gets every feature* |
| **Pro owner** | no Pro price · Cloud **upgrade** · opens on yearly |
| **Cloud owner** | *Manage subscription* · no prices, no buy |
| **From a lock** | that feature's details · its plan picked · no scroll |
| **From the drawer** | plan overview: name · promise · every feature · no scroll |
| **Price** | name left · store price right · *per year/month* · trial · launch line |
| **Cloud, no account** | claim intro first · receipt needs the profile id |
| **Pending** | *waiting for the store* |
| **Renewal note** | only while monthly or yearly is picked |
| **Restore** | without buying · next to Terms + Privacy · gone once Pro or Cloud is held |

## Where a lock goes in code

- affordance: `FeatureLockIcon` · `FeatureLockChevron` · `LockedFeatureCard`
- opens `PaywallLauncher.require(context, feature)`
- use case throws `TranslatedWarning(AppError.featureLocked)`
- `FeatureGateBuilder` rebuilds on plan, sign-in, verdict, book change
- gated page = one line in `destination_feature.dart`
- readable after lapse: `LockedRecords.readable` → `ReadOnlyFeatureBanner`
