## Three tiers

Each higher tier contains everything below it.

| Tier | How you pay | What it is |
|---|---|---|
| **Free** | — | the full budgeting app on one phone, no account needed |
| **Pro** | once, €24.99 | Free + the power features, **works offline**; the server is only ever read |
| **Cloud** | monthly, yearly or lifetime | Pro + sync, devices, shared family books, up to 3 books, web dashboard |

- Every Cloud plan includes Pro, the subscriptions too.
- Monthly, yearly and lifetime Cloud unlock exactly the same thing.
- **Tier** = a feature package (Free, Pro, Cloud). **Plan** = a way to pay for one (once, monthly, yearly, lifetime).

## Cloud belongs to the book

Features in the open book = the higher of what I bought and what the book's **owner** pays for.

| User | Own private book | A shared Cloud book |
|---|---|---|
| Free | Free | Cloud |
| Pro | Pro | Cloud |
| Cloud | Cloud | Cloud |

- The owner pays; invited members get every feature, only inside that book.
- When the owner stops paying, the book stops syncing for everyone in it; its data stays readable.
- Feature checks depend on the **active book**, not only on the user.

## Accounts and the phone

An account is not a tier: Free and Pro never need one. The phone's states (Local Free, Local Pro, free account, paused, Cloud, signed out), the claim and the glossary live in [Accounts & sync](/accounts/).
