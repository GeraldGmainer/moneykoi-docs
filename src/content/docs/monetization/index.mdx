## Three tiers

| Tier | Pay | What |
|---|---|---|
| **Free** | — | full budgeting app · one phone · no account |
| **Pro** | once · €24.99 | Free + power features · **offline** |
| **Cloud** | monthly · yearly · lifetime | Pro + sync · devices · shared books · ≤ 3 books · web |

- each tier includes the one below
- every Cloud plan includes Pro · all Cloud plans unlock the same
- **tier** = feature package · **plan** = how you pay

## Cloud belongs to the book

| User | Own book | Shared Cloud book |
|---|---|---|
| Free | Free | **Cloud** |
| Pro | Pro | **Cloud** |
| Cloud | Cloud | Cloud |

- the **owner** pays → members get every feature, in that book only
- owner stops paying → book stops syncing · data stays readable
- checks follow the **active book**

## Accounts

- an account is **not** a tier · Free + Pro never need one
- phone states, claim, words → [Sign-in & accounts](/accounts/)
